# フェーズ6: 保存・エクスポート・仕上げ - 操作手順書

## 概要

エディタの操作性向上機能。Undo/Redo、PNG出力、キーボードショートカット、保存状態インジケータを提供する。

## 前提条件

- アプリケーションが起動していること
- ユーザーがログイン済みであること
- プロジェクトのエディタ画面を開いていること

## Undo/Redo（元に戻す/やり直す）

### 操作対象
以下の操作がUndo/Redoの対象となる：
- 家具の追加
- 家具のドラッグ移動
- 家具の90°回転
- 家具の削除
- 壁の描画確定
- 矢印キーによる家具移動

### 操作方法

#### ツールバーのボタン
- 「↩」ボタン: 元に戻す
- 「↪」ボタン: やり直す
- 操作履歴がない場合、ボタンは無効化（薄く表示）される

#### キーボードショートカット
- `Ctrl + Z`: 元に戻す
- `Ctrl + Y` / `Ctrl + Shift + Z`: やり直す

### 注意事項
- 履歴は最大50件まで保持される
- 新しい操作を行うとRedo履歴はクリアされる
- ページをリロードすると履歴はリセットされる

## PNG出力

### 操作手順
1. ツールバーの「PNG出力」ボタンをクリック
2. PNGファイルが自動的にダウンロードされる
3. ファイル名: `{プロジェクト名}_{日付}.png`

### 注意事項
- キャンバス全体が2倍解像度で出力される
- 背景色、グリッド、壁、家具が含まれる

## キーボードショートカット一覧

| ショートカット | 機能 |
|------------|------|
| `Ctrl + Z` | 元に戻す (Undo) |
| `Ctrl + Y` | やり直す (Redo) |
| `Ctrl + S` | 手動保存 |
| `Delete` / `Backspace` | 選択した家具を削除 |
| `R` | 選択した家具を90°回転 |
| `Escape` | 選択解除 / 壁描画キャンセル |
| `矢印キー` | 選択した家具を10mmずつ移動 |

### ショートカットヘルプ
- ツールバー下部の「?」ボタンをクリックするとショートカット一覧モーダルが表示される

### 注意事項
- テキスト入力フィールドにフォーカスがある場合、ショートカットは無効化される
- `Ctrl + S`はブラウザのデフォルト保存ダイアログを抑制し、手動保存を実行する

## 保存状態インジケータ

エディタヘッダーのプロジェクト名の横に保存状態が表示される。

| 表示 | 意味 |
|------|------|
| (非表示) | 変更なし |
| 保存中... | 自動保存処理中 |
| &#10003; 保存済み (X秒前) | 保存完了。相対時刻を表示 |
| &#9888; 保存失敗 | 保存エラー発生 |

### 自動保存の動作
- 変更検出後2秒のデバウンスで自動保存が実行される
- `Ctrl + S`で即座に手動保存が可能
- Undo/Redo操作も保存対象（サーバーに反映される）
